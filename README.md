# Virinda Store Annual Report Excel Practice Project

## Project Description

This is a Data Analysis and Dashboard Practice Project built in Microsoft Excel. The goal of the project was to analyze the sales and order data of the company and build a dashboard that would provide clear insight into a number of business-related questions.

The dashboard displays the information needed to quickly assess the sales, customer base, order status, and sales channels of the Virinda retail network.

The goal of the project was to learn how to perform various operations in Microsoft Excel, including analyzing sales and order information, identifying trends and key insights, visualizing and building charts, comparing the characteristics of different customer segments and sales categories, and building an interactive dashboard in Excel.

The dashboard makes it possible to quickly find answers to questions about sales and orders, such as:

• how sales and orders are related to time;

• which states make the most sales;

• how sales are distributed among males and females;

• how age and sex influence purchasing;

• which sales channels generate the most numerous purchases;

• what share of orders are delivered, cancelled, refunded, and returned;

• which categories of goods contribute most to sales.

• how the performance per month changes depending on multiple criteria.
